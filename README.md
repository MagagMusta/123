# 📚 ПИ-17 · Расписание и учебный день

Сайт-клон **sfedu-pi17.github.io** (расписание группы ПИ-17, ЮФУ) с доработками:
заметки в расписании, ДЗ/контрольные от всех, объявления, SQLite-база, регистрация
с подписью автора и админка для утверждения правок.

## План реализации (и что уже сделано)

### 1. Анализ оригинала
- Данные расписания взяты из того же источника, что у оригинального сайта
  (публичная Google-таблица группы) → сохранены в `public/schedule.csv` и импортированы в БД.
- Сохранены механики оригинала: верхняя/нижняя неделя, стрелки ‹ ›, кнопка «Сегодня»,
  сетка дней пн–сб, 6 пар с временем (`8:00-9:35 … 17:40-19:15`), формат/преподаватель/аудитория,
  бейдж «отменена».

### 2. Доработки по ТЗ
| Требование | Реализация |
|---|---|
| Только числа недель, слово «неделя» убрать | Дробь **Верхняя / Нижняя** числителем-знаменателем без слова «неделя»; активная подсвечивается |
| Тёмная тема Apple | Палитра `#000/#1c1c1e/#f5f5f7`, системные синтаксические цвета Apple (systemBlue #0a84ff и др.), шрифт SF Pro |
| Liquid Glass + анимации | `backdrop-filter: saturate(180%) blur(24px)`, полупрозрачные панели с внутренней подсветкой, «живые» размытые орбы на фоне, keyframes `fadeUp/pop/slideDown`, hover-микровзаимодействия |
| Пометки в расписании | Личные заметки 📝 к паре и к дню (видны только автору) + общая пометка-стикер 📌 на паре через предложение админу |
| Контрольные и ДЗ | Отдельная вкладка: 🔴 контрольные / 🔵 ДЗ, срок сдачи, «через N дней», просрочка, отметка о выполнении |
| Объявления | Вкладка «Объявления»: предложить может любой вошедший, публикует админ |
| Кнопка «Внести правки» в конце сайта | Кнопка под расписанием + кнопки ✖/📝/✏️ на каждой паре (отменить, пометка, изменить, добавить новую) — всё уходит в очередь на утверждение |
| Убрать публичную админ-панель, оставить только утверждение | На сайте никакой админки нет; `/admin` доступен **только** аккаунту с ролью admin |
| БД | SQLite (`data.db`): users, sessions, schedule_entries, schedule_proposals, notes, tasks, announcements |
| Регистрация и подписи | Вход/регистрация обязательны для любого действия; каждая правка, задание и объявление подписаны автором (видно всем) |

### 3. Структура
```
server.js          — Node HTTP-сервер + REST API (без фреймворков)
public/index.html  — основной сайт (3 вкладки)
public/app.js      — клиент
public/style.css   — Apple dark + liquid glass
public/admin.html  — админка (/admin): утверждение правок, публикация объявлений
public/schedule.csv— исходные данные расписания (для первичного импорта)
```

### 4. Проверка (пройдена)
- API протестирован curl: регистрация → задания/правки/объявления/заметки;
  неавторизованный POST → 401; студент в админ-API → 403.
- UI проверен Puppeteer: рендер 6 дней и пар, переключение недель, регистрация,
  заметка, вкладки заданий/объявлений, админка — ошибок в консоли нет.

## Запуск

```bash
npm install        # нужна только better-sqlite3
npm start          # http://localhost:3000 , админка: http://localhost:3000/admin
```

При первом запуске автоматически создаётся БД и администратор:
**login:** `admin` · **password:** `admin123` (смените, удалив `data.db` и изменив
пароль в `server.js`, либо через `UPDATE users SET ...`).

## Роли
- **Гость** — смотрит расписание, задания, объявления.
- **Студент** (регистрируется) — личные заметки, скидывает ДЗ/контрольные,
  предлагает правки расписания и объявления (везде с подписью).
- **Админ** (`/admin`) — утверждает/отклоняет правки расписания, публикует объявления.
